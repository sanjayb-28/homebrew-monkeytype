# Homebrew Tap for Monkeytype Desktop

Installs the offline Electron app from
[sanjayb-28/monkeytype](https://github.com/sanjayb-28/monkeytype), maintained on
`electron/offline-upstream`. The older `monkeytype-desktop` Tauri app is retired.

## Install

```bash
brew tap sanjayb-28/monkeytype
brew install --cask monkeytype
```

## Update

```bash
brew upgrade --cask monkeytype
```

From version 0.2.0, you can also use **About → check for updates** or
**Monkeytype → Check for updates…** in the app. Homebrew installations offer
**Update and restart**, preserving local settings and typing history.

## Uninstall

```bash
brew uninstall --cask monkeytype
```
